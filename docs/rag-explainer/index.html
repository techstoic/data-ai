RAG, Step by Step

Retrieval-Augmented Generation, built from the bottom up. Use the arrow keys or the buttons. Toy ES300h manual: the numbers are illustrative, so check your real manual.

1. An LLM is a closed-book student

It read a huge library once. Then its memory froze. It never saw your owner's manual.

🙋 You
What tire pressure does my ES300h need?
🧠 LLM
📕 book closed
Use 32 psi.
GUESS: NOT FROM YOUR MANUAL

The answer sounds confident, but it can be wrong. This is called a hallucination.

2. Fix: make it an open-book exam

Paste the right page into the prompt, before the question. Now the model reads. It does not guess.

PROMPT SENT TO THE LLM
📄 Manual p.412: Front and rear tire pressure: 36 psi, checked cold.
Question: What tire pressure does my ES300h need?
🧠 LLM
📖 book open
36 psi, checked cold (p.412).
GROUNDED: READ FROM THE PAGE
A + G in RAG: augment the prompt with the page, then generate the answer.

3. Problem: you cannot paste the whole library

The manual has 600 pages. A prompt has a size limit, and every word costs money and time.

📚 600 pages

Prompt capacity

OVERFLOW: TOO BIG, TOO SLOW, TOO EXPENSIVE

You only need the 1 to 3 paragraphs that matter. A search finds them. That search is the R: Retrieval.

4. Cut the manual into chunks

Split the text into small pieces. Each piece covers one idea. These pieces are called chunks.

Real systems use chunks of about 200 to 800 words, often with a small overlap so ideas do not get cut in half.

5. Turn each chunk into a point on a map of meaning

An embedding model turns text into a list of numbers. Use the numbers as coordinates. Text with similar meaning lands close together.

Tires and rotation sit close together. Bluetooth is far away. Real embeddings have hundreds to thousands of dimensions. We draw 2 so you can see them. A vector database stores these points.

6. Your question becomes a point too, then find the nearest

The question goes through the same embedding model. It lands on the same map. The closest chunks are the most relevant ones.

7. Augment: paste the top 3 chunks into the prompt

Only the winners go in. The prompt is now small, cheap, and full of the right facts.

8. Generate: the LLM answers from the sources

The model reads the pasted chunks, writes the answer, and cites the page so you can check it.
